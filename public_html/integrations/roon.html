Roon

Pairs with Roon for external zone discovery and control, while Music Core uses Tater Tube as the current music library and playback source.

Audio v1.2.1 Optional
Source module

integrations/roon.py

Description

What it provides

Roon Core pairing and zone transport control for installs that still need direct Roon access.

speakermedia_playeraudio_outputroon_zone
Behavior

Operational notes

  • Registration can continue after the initial request while the user authorizes Tater in Roon.
  • Roon zones are not used as Music Core stream targets; Tater Tube handles the current music catalog and playback flow.
  • Keep Roon configured only when you need direct external zone control outside the Tater Tube Music Core path.
