Ways to run Tater

Choose the host that already fits your home.

The macOS app is the quickest native path. The other options run the same TaterOS experience on a server or container you control.

Tater for macOS

Install the complete Tater server as a native Apple Silicon Mac app with a private runtime, menu bar controls, and automatic updates.

Best for: Apple Silicon Macs running macOS 15 or newer that want the simplest native Tater setup.

Run Tater first, then pair Little Spud.

Little Spud does not replace the Tater server. It pairs to your Tater through Spud Hub and brings chat, voice, Home controls, Music Core, notifications, snapshots, and video clips to your phone or tablet.
