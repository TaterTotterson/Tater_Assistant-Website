A few good questions

Curious potatoes
welcome.

What do I need to run Tater?

A supported computer or home server, plus an AI model. You can run a model locally or connect a remote provider. The setup guide helps you choose a starting point.

Do I need special hardware?

You can start with Tater's browser interface. Voice satellites are optional, and Little Spud pairs your phone with a running Tater server.

Does everything stay local?

Tater runs on hardware you control and supports local AI models. Remote model providers and online integrations send the requests they need to those services. You choose which ones to connect.

Does it work with my smart home?

Tater supports optional integrations including Home Assistant, Philips Hue, and other services. Check the integration directory for your devices.

Where are the technical docs?

Right here. The Tater docs cover setup, voice, integrations, skills, and the pieces under the hood.
